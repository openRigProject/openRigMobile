# openRigMobile

Mobile ham radio application for iOS and Android. Provides rig control, QSO logging, DX cluster spots, and device management.

## Requirements

- [Flutter](https://flutter.dev) SDK
- Xcode (iOS)
- Android SDK (Android)

## Building

```bash
# iOS
flutter build ios

# Android
flutter build apk
```

## Running (development)

```bash
flutter run
```
